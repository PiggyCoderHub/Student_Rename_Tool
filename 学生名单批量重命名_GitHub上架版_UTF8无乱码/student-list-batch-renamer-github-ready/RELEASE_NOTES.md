# Release Notes

## v1.0.0

这是适合 GitHub 发布的首个整理版本。

### 功能亮点

- 支持学生名单批量导入。
- 支持导入前预览和勾选确认。
- 支持全选、全不选、反选。
- 支持学号、姓名、班级字段自动识别。
- 支持学号数字格式自动修正。
- 支持重复学号自动更新。
- 支持根据学生信息批量匹配和重命名提交文件。
- 支持启动失败日志输出。

### 编码处理

- GitHub 文档使用 UTF-8。
- CSV 模板使用 UTF-8 BOM。
- BAT 文件使用 UTF-8 BOM + `chcp 65001`。
- ZIP 使用 UTF-8 中文文件名。

### 注意事项

首次运行前请安装 Python 3.8+，并运行 `安装依赖.bat`。
