# 编码与中文乱码处理说明

本项目需要同时兼容 GitHub 页面显示和 Windows 本地运行，因此对编码做了统一处理。

## 一、仓库文本编码

- `.py`：UTF-8。
- `.md`：UTF-8。
- `.txt`：UTF-8，部分面向 Windows 记事本的说明文件可带 BOM。
- `.csv`：UTF-8 BOM，方便 Excel 识别中文。
- `.bat`：UTF-8 BOM，并在第一行后设置 `chcp 65001 >nul`。

## 二、为什么不用 GBK 保存 BAT

GBK BAT 在部分中文 Windows 上运行较稳，但上传到 GitHub 后容易显示乱码。因此本上架版采用 UTF-8 BOM + `chcp 65001`。这样 GitHub 页面显示正常，Windows 10/11 运行也更稳定。

## 三、如果个别电脑中文 BAT 仍异常

使用英文备用入口：

```bat
START_HERE.bat
```

它的文件名和大部分提示为英文，但启动后的程序界面仍为中文。

## 四、CSV 中文乱码处理

如果直接双击 CSV 后中文乱码，建议：

1. 改用 `学生名单导入模板.xlsx`。
2. 或在 Excel 中通过“数据 -> 自文本/CSV”导入，并选择 UTF-8。
3. 不要把 CSV 另存为 ANSI。

## 五、GitHub 上传注意事项

上传前不要包含：

- `data/students.db`
- `__pycache__/`
- `.pyc`
- `run_error.log`
- 本地压缩包

本仓库已提供 `.gitignore`，正常使用 Git 提交时会自动忽略这些文件。
