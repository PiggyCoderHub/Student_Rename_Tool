# 使用手册

## 一、首次运行

1. 解压项目或从 GitHub 下载源码。
2. 确认电脑已安装 Python 3.8 或以上版本。
3. 双击 `安装依赖.bat`。
4. 双击 `启动程序.bat`。

如果中文启动文件异常，可以双击 `START_HERE.bat`。

## 二、导入学生名单

1. 打开程序。
2. 进入学生信息管理。
3. 选择批量导入名单。
4. 选择名单文件。
5. 在预览表中检查识别结果。
6. 左侧“是否导入”为“是”的记录才会导入。
7. 可点击“全选”“全不选”“反选”。
8. 点击“确认导入已选择”。

## 三、名单文件要求

推荐使用 `学生名单导入模板.xlsx`。

最低要求：

- 学号
- 姓名

可选字段：

- 班级
- 电话
- 邮箱
- 备注

如果名单没有表头，建议第一列为学号，第二列为姓名。

## 四、批量重命名

1. 确认已经导入学生名单。
2. 进入批量重命名功能。
3. 选择学生提交文件所在文件夹。
4. 确认处理。
5. 程序会根据学号、姓名和文档内容进行匹配。

建议学生提交文件名包含学号或姓名，例如：

```text
202501010001_张三_实验报告1.docx
张三_课程作业.docx
```

## 五、故障处理

### 程序打不开

运行 `调试启动.bat`，查看 `run_error.log`。

### 缺少依赖

运行：

```bat
安装依赖.bat
```

### 中文乱码

优先使用本仓库中的文件，不要用压缩软件或编辑器重新保存为 ANSI 编码。CSV 推荐使用 `.xlsx` 替代。
